# Anatomical

Интерактивный 3D-атлас тела человека. В нём 250 структур в шести анатомических слоях. Можно сравнивать слои, читать описания структур и двигать суставами обеих сторон тела.

## Запуск

Распакуйте ZIP, откройте терминал в распакованной папке и запустите:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

На Windows вместо `python3` можно использовать `py`. Откройте [http://localhost:8000](http://localhost:8000) в браузере с WebGL 2. Библиотеки, шрифты и 3D-модели входят в архив. Для обычного просмотра после распаковки нужен только локальный HTTP-сервер.

## Управление

- Перетаскивание вращает камеру. Колесо мыши, жест сведения пальцев и кнопки масштаба приближают модель.
- Нажатие на название слоя включает его отдельно. Кнопки с глазом совмещают слои, а ползунок задаёт прозрачность выбранного слоя.
- Нажатие на структуру открывает название и описание. Её можно приблизить или изолировать.
- Выберите сустав и сторону в инспекторе, используйте ползунок угла или запустите показ движения. В режиме с иконкой ладони можно тянуть за метки суставов на модели.

Положение костей и деформация мягких тканей рассчитаны для учебного показа суставного движения. Геометрия описывает одну референсную модель тела.
