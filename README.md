# Nanette Studio

Статический сайт: HTML, CSS, JavaScript. Сборка, npm и сервер приложений не нужны.

## Структура

В корне: index.html, style.css, script.js, .nojekyll. В assets/: logo.svg, mark.svg, kasia.jpg, marta.jpg, natalia.jpg, salon.jpg.
Все пути относительные. Сайт работает и в корне домена, и по адресу /имя-репозитория/.

## Публикация

Загрузите содержимое этой папки в корень репозитория. Settings → Pages → Deploy from a branch → выберите ветку с файлами → /(root) → Save.
Точный адрес публикации смотрите в Settings → Pages. Результат публикации проверяйте в Actions для последнего коммита.

## Пользовательский домен

Используется `nanette-pl.duckdns.org`; файл CNAME включён и должен лежать в корне репозитория. В Settings → Pages → Custom domain должен быть указан тот же домен. DNS должен направлять домен на GitHub Pages. Состояние проверки DNS и сертификата HTTPS смотрите в Settings → Pages. Перенос файлов в другой репозиторий сам по себе не переносит настройки домена.

## Локальная проверка

python3 -m http.server 8000

Откройте адрес сервера в браузере. Можно также открыть index.html напрямую. Фотографии и шрифты не требуют внешних загрузок. Запись в Booksy и Google Maps требуют интернета.

## Редактирование

Тексты и ссылки: index.html. Палитра и адаптация: style.css. Меню и анимации: script.js.
Фотографии сотрудниц и салона подключены из assets. Для обновления заменяйте файлы с сохранением имени, расширения и регистра.
Логотип logo.svg — векторная реконструкция предоставленного изображения. Цены и расписание не выдуманы; текущие сведения о записи находятся в Booksy.
