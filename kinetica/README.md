# Кинетика — анатомия движения

Русскоязычный интерактивный 3D-атлас. 738 реальных структур BodyParts3D 4.0, четыре движения, слои мышц/костей/соединительных тканей, выбор структур, пауза, ползунок фазы, скорость, повтор и листание карточек.

## Запуск

Нужен современный браузер с WebGL и Python 3. Из папки проекта:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Двойное нажатие index.html не работает из-за ограничений браузера на загрузку локальной геометрии. Для публикации на любом статическом хостинге загрузите содержимое dist. Сборка, npm и API-ключи не нужны. Геометрия и Three.js включены; шрифт Manrope запрашивается через Google Fonts с системной заменой при отсутствии интернета.

Управление: перетаскивание — вращение, колесо/жест двумя пальцами — масштаб; нажмите на структуру для исходного названия. Движения выбираются слева, стрелками, клавишами ←/→ или свайпом по карточке. Ползунок меняет фазу. Кнопка ▶ запускает анимацию вперёд и обратно. Сброс ракурса находится вверху 3D-панели.

## Ограничения

Исходная модель — референс взрослого мужского тела. Анимация жёстких сегментов условная: мягкие ткани не деформируются физически, лопатка не анимирована, скольжение колена не моделируется. Для подъёма на носок показано подошвенное сгибание свободной стопы, а не динамика опорного тела. Подсветка отражает выбранные участвующие мышцы, а не ЭМГ или проценты усилия. Соединительный слой включает связки и другие ткани, а не только сухожилия. Названия выбранных структур сохранены на английском, как в наборе данных.
