# SafeRate

Telegram-бот для эвристической проверки исходного кода. Минималистичный русский интерфейс, inline-кнопки, отчёты TXT/JSON. Python 3.11+, без сторонних зависимостей.

## Самый простой запуск через .env

Скопируйте .env.example в .env рядом с bot.py. В обычном терминале Windows:

```bat
copy .env.example .env
notepad .env
```

Сохраните в .env:

```dotenv
TELEGRAM_BOT_TOKEN=ваш_настоящий_токен_от_BotFather
PUBLIC_BOT=1
```

Затем выполните `python bot.py` (на Linux/macOS: `python3 bot.py`). Для копирования на Linux/macOS используйте `cp .env.example .env`. PUBLIC_BOT=1 открывает доступ всем в личных сообщениях. Не публикуйте .env и не отправляйте его другим: он содержит токен. В .gitignore он исключён; ZIP проекта его также исключает. Это простой формат KEY=VALUE, без подстановки переменных и выполнения команд.

## Запуск

1. Создайте бота через официальный @BotFather в Telegram с именем SafeRate и получите токен. При запуске программа также устанавливает отображаемое имя SafeRate через Telegram API. Username задаётся отдельно в BotFather и должен быть свободен.
2. Публичный режим включается через PUBLIC_BOT=1: любой пользователь может писать боту лично. Группы не поддерживаются. Для закрытого режима уберите PUBLIC_BOT и задайте ALLOWED_USER_IDS числовыми ID через запятую.
3. В терминале из папки проекта выполните:

```bash
read -rsp 'Bot token: ' TELEGRAM_BOT_TOKEN; echo
export TELEGRAM_BOT_TOKEN
export PUBLIC_BOT=1
python3 bot.py
```

Токен вводится скрыто, не записывайте его в исходники. Для постоянного запуска используйте секреты вашего хостинга и supervisor/systemd. Нужен исходящий HTTPS к api.telegram.org. Один экземпляр на токен; запуск удаляет webhook, сохраняя очередь обновлений. Отправьте /start и файл документом. Никакой регистрации в сторонних сервисах проверки нет.

### Windows PowerShell

```powershell
$token = Read-Host 'Токен бота' -AsSecureString
$env:TELEGRAM_BOT_TOKEN = [System.Net.NetworkCredential]::new('', $token).Password
$env:PUBLIC_BOT = '1'
py bot.py
```

Выполняйте команды из распакованной папки SafeRate. На хостинге добавьте TELEGRAM_BOT_TOKEN как секрет и PUBLIC_BOT со значением 1 в настройках переменных окружения. Файл .env рядом с bot.py читается автоматически. Существующие переменные окружения имеют приоритет.

## Проверки

```bash
python3 -m unittest discover -s tests -v
python3 scanner.py /path/to/source.py
python3 scanner.py /path/to/project.zip
```

14 групп текстовых правил плюс проверка Python AST на shell=True: запуск процессов, динамический код, скачивание и запуск, секреты, чтение чувствительных файлов, сеть, обфускация, автозапуск, удаление данных, отключение TLS, десериализация, lifecycle-скрипты и HTML-вставки. Правила находятся в scanner.py. Сетевые ссылки сами по себе отмечаются как информация, а не вредоносность. Фрагменты исходников и значения секретов не включаются в отчёт; имена файлов сохраняются.

## Границы анализа

Это рабочий MVP, а не замена VirusTotal и не гарантия безопасности. Нет антивирусных движков, поведенческой песочницы, межпроцедурного анализа, анализа потоков данных и проверки уязвимых зависимостей. Возможны ложные срабатывания и пропуски, включая обфусцированные и многострочные конструкции. Бинарники, вложенные архивы, неподдерживаемые кодировки пропускаются с явным указанием. Просматривайте исходники вручную, особенно установочные скрипты.

До 15 МиБ загрузки, 2 МиБ на исходник, 300 записей ZIP, 30 МиБ распакованных данных, коэффициент сжатия не более 200, 2000 находок. Архивы читаются в памяти, не извлекаются на диск; пути с обходом, симлинки, дубликаты и зашифрованные ZIP отклоняются. Код никогда не запускается и зависимости загруженного проекта не устанавливаются. Запускайте самого бота непривилегированным пользователем с ограничением памяти/CPU на хостинге. Обработка последовательная; публичный доступ поддерживается, но для большой нагрузки потребуются очередь заданий и отдельные воркеры. Между проверками одного пользователя действует интервал 10 секунд.

Исходники остаются в памяти на время проверки. До 20 отчётов хранятся в памяти с TTL 15 минут; физическая очистка происходит при следующем обновлении Telegram или остановке процесса. Кнопка удаления очищает запись в памяти, но не удаляет историю Telegram. Передача файлов Telegram означает передачу третьей стороне. Не загружайте реальные секреты. Сетевые ошибки журналируются без URL, токена и исходников.

## Статус проверки

Автотесты проверяют детектирование, редактирование секретов, ZIP traversal, бомбы, симлинки, лимиты, ошибки синтаксиса, пропуски и сценарии бота через подставной Telegram API. Реальное соединение Telegram и отправка сообщений требуют вашего токена и отдельно не проверены.
